Gemini API key

This extension uses your own free Gemini API key, entered here — nothing is sent through a shared server, and there's no daily limit imposed by anyone but Google's own free tier.

Don't have a key yet?

  1. Open aistudio.google.com/apikey
  2. Sign in with your Google account
  3. Click Create API key and copy it
  4. Paste it on the left and press Save key

It's free and needs no credit card.
